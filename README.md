# Personal Portfolio

A modern, responsive developer portfolio showcasing my technical skills, featured projects, education, and software development journey.

## Overview

This portfolio highlights my work in full-stack development and backend engineering, with a focus on building reliable applications, optimizing performance, and creating polished user experiences.

## Features

- Responsive design for desktop and mobile
- Animated scroll-reveal effects
- Technical skills and technology stack
- Featured projects with project links
- Education and academic background
- Contact section with email and LinkedIn links
- Resume access
- Smooth navigation and back-to-top button

## Tech Stack

- **Frontend:** React.js, Vite, Tailwind CSS
- **Programming:** JavaScript
- **Tools:** Git, GitHub, Vercel

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_REPO
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Deployment

The portfolio can be deployed using Vercel that supports Vite applications.
